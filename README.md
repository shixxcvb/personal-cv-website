## ✨ Design & Architectural Features

- **Charlene's Creative Universe:** Dreamy lavender, soft pink, periwinkle, and deep plum palette with ambient glow layers and starburst details.
- **Oversized Typography Project Gallery:** Zero static screenshots, fake iframes, or mock browser windows. Instead, large kinetic typography rows that respond on hover with distinct project colors, abstract animated SVG motifs, and direct live links.
- **Experimental Centerpiece Hero:** Massive expressive typography, layered letter compositions, sticker labels with playful angles, and interactive portrait vessel with initials `CC`.
- **Cosmic Skills Cluster:** Interactive category switching ("All", "Code", "Tools", "Design") and floating tech cards with hover reactions.
- **Academic Constellation Milestones:** Winding educational journey for DNSC, Southern Davao NHS, and Panabo Central ES with truthful dates.
- **Printable Curriculum Vitae Modal:** Formatted executive layout with a dedicated print trigger (`window.print()`).
- **Full Responsiveness & Touch Support:** Optimized across mobile (320px+), tablet, and desktop screens with keyboard accessibility.

## 💻 Local Development Setup

### Prerequisites
- Node.js (version 18 or later)
- npm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/shixxcvb/charlene-personal-cv.git

# Enter the project directory
cd charlene-personal-cv

# Install dependencies
npm install
```

### Running Locally
```bash
npm run dev
```
The app will run at `http://localhost:3000`.

### Building for Production
```bash
npm run build
```
The compiled static assets will be output to the `dist/` directory.

---

## 🌐 Deploying to Vercel

1. Push this repository to your GitHub account: `https://github.com/shixxcvb/charlene-personal-cv`.
2. Go to [Vercel](https://vercel.com/) and click **"Add New Project"**.
3. Import the `charlene-personal-cv` repository.
4. Configure the project settings:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. Click **Deploy**. Vercel will build and assign a production URL.
